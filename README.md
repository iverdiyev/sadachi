# Sadachi — локальный аналог TickTick для Android

Независимый open-source планировщик задач и заметок на русском. Без аккаунта, рекламы и облака. Проект не связан с TickTick и не повторяет все его возможности.

## Версия 0.6.1

- Основной Android ID: **`com.ilkinsadachi`**.
- Компактный редактор: дата и папка сверху, крупный заголовок H1, ниже описание и чек-лист. На пустом поле нажмите **＋**, чтобы открыть редактор новой задачи.
- Быстрый ввод одной строкой или заголовка с описанием через перевод строки.
- Жирный, курсив, подчёркивание, зачёркивание, моноширинный текст и маркеры через панель **Aa · Стиль**.
- Небольшие виджеты «Сегодня» и «Список», без большой карточки прогресса. Размер меняется долгим нажатием на виджет.
- Светлая/тёмная тема и отдельная светлая/тёмная иконка лаунчера: **⋯ → Иконка приложения**. Лаунчер может обновить её не сразу.
- Офлайн-диктовка русского текста через микрофон — встроенная модель Vosk.
- Локальные JSON-копии и перенос заметок из прежнего приложения.

Новые скриншоты этой версии пока не создаются и не публикуются. Старые изображения в истории не показывают новый интерфейс.

## Установка и перенос старых заметок

APK находятся в [последнем релизе](https://github.com/iverdiyev/sadachi/releases/latest):

- **Sadachi-9.apk** — основное приложение `com.ilkinsadachi`.
- **Sadachi-legacy-9.apk** — обновление прежнего ID `ru.svoizadachi.app` для переноса. Оно отображается как **«Sadachi · перенос»**.

Смена ID — это отдельное приложение. Android сам не переносит его приватные данные.

Если уже пользуетесь старой версией:

1. Не удаляйте её. Установите файл **legacy** поверх старой версии с тем же ключом подписи.
2. Установите основное приложение `com.ilkinsadachi`.
3. В новом приложении выберите **⋯ → Перенос и резервные копии → Перенести из старого приложения**.
4. После успешного копирования старые напоминания отключаются, чтобы не дублироваться. Старые заметки не удаляются. Проверьте результат перед удалением старого приложения.

Перенос доступен только приложениям с совпадающей подписью. При несовместимой подписи ничего не удаляйте: сохраните в старой версии JSON-копию и импортируйте её в новой. JSON содержит текст заметок в открытом виде — выбирайте внутреннее хранилище телефона и не публикуйте файл. Повторный импорт JSON добавит дубли.

## Голосовой ввод

Нажмите микрофон в панели добавления или в редакторе. После разрешения Android обработка идёт **на телефоне**, запись не загружается и не сохраняется как аудиофайл. Распознанный текст можно исправить перед сохранением задачи.

Это **ASR-модель**, а не чат-LLM: Vosk `vosk-model-small-ru-0.22`, примерно 45 МБ в архиве. Она входит в APK GitHub-сборки и при первом использовании распаковывается в приватную папку приложения. На время диктовки требуется дополнительная оперативная память. Модель загружается по запросу и освобождается после завершения; микрофон прекращает работу при закрытии диалога или уходе из приложения. Сессия ограничена 60 секундами.

Точность зависит от шума, произношения и микрофона. Фразы `через две минуты`, `через пятнадцать минут`, `завтра в девять утра` обрабатывает локальный парсер даты. Уточняйте время в предпросмотре.

## Напоминания

Разрешите уведомления и точные таймеры. На OnePlus проверьте фоновую работу и ограничения батареи. Если уведомления приходят только после открытия, в **⋯ → Напоминания** доступны диагностика, настройка фона и включаемый пользователем **«Надёжный режим»** системного будильника Android.

Надёжный режим может показывать значок ближайшего будильника, но приложение по-прежнему показывает уведомление, а не включает мелодию будильника. Принудительную остановку приложения и запрет уведомлений он не обходит. Доставку на конкретной прошивке нужно проверять с заблокированным экраном без открытия приложения.

## Локальные данные и обновления

Заметки, папки, чек-листы, настройки и распакованная речевая модель остаются на устройстве. В сеть уходят только запросы к GitHub для проверки версии и скачивания APK. Диктовка работает без сети. Установка обновления требует подтверждения Android.

Старый ID получает совместимый файл через `update.json`, новый — через `update-com.ilkinsadachi.json`. Перед установкой проверяются хеш, ID пакета, версия и подпись. Ключ GitHub-сборок хранится в Actions Secrets, а не в исходниках.

## Сборка

JDK 17, Gradle 8.9, Android SDK 35 и Python 3:

```sh
python .github/scripts/prepare-voice.py
gradle :app:testDebugUnitTest :app:assembleDebug
```

Первый шаг скачивает официальную модель Vosk со сверкой SHA-256; при недоступности исходного сервера используется побайтово идентичное проверяемое зеркало Rhasspy. Модель включается в APK. Сборка без модели не должна публиковаться. Для совместимого APK старого ID: `gradle :app:assembleDebug -PsadachiApplicationId=ru.svoizadachi.app`.

Локальная debug-подпись Android Studio может отличаться от GitHub-подписи. Не удаляйте приложение с важными заметками при ошибке установки.
