# Свои задачи — open-source Android-планировщик (v0.1.1)

Нативное Android-приложение **без рекламы, регистрации, подписок, облака и доступа к интернету**. Всё хранится локально на телефоне. Интерфейс на русском.

## Что уже есть

- Задачи с отметкой «готово», редактированием и удалением.
- Вкладки «Активные», «Сегодня», «Предстоящие», «Готово».
- Умный ввод русских дат и времени: `Домашка завтра в 18:00`, `Оплатить через 3 дня в 9 утра`, `Сдать зачёт 5 ноября в 14:00`, `Дз в понедельник в 8`.
- Повторы `каждый день в 9:00`, `каждую неделю в 19:00`.
- Системные уведомления, кнопки «Готово» и «Через 10 минут».
- Восстановление напоминаний после перезагрузки телефона.

**Ограничения v0.1:** это MVP, а не точная копия TickTick. Пока нет синхронизации, проектов, тегов, календаря, виджетов и резервной копии. При удалении приложения задачи исчезнут. Для задачи с одной датой, но без времени уведомление не включается — уведомление появляется, когда указано время. Уведомления зависят от разрешений Android, энергосбережения и работы OEM-прошивки.

## Android Studio — рекомендуемый способ проверки v0.1.1

1. Распакуйте архив проекта в папку без русских букв в пути, например `C:\Dev\Sadachi`.
2. Android Studio → **File → Open** → выберите **саму папку проекта** (где лежат `settings.gradle` и `build.gradle`). Не выбирайте `app`.
3. При первом открытии разрешите Gradle Sync и загрузку Android SDK Platform 35, если Android Studio предложит.
4. В **Settings → Build, Execution, Deployment → Build Tools → Gradle** укажите **Gradle JDK = Embedded JDK (17 или новее)**; используем Gradle 8.9, указанный в `gradle/wrapper/gradle-wrapper.properties`.
5. В меню **Build → Make Project** проверьте, что ошибок нет.
6. В **Project → app → src → test → java → ru.svoizadachi.app → TaskDateParserTest** нажмите правой кнопкой → **Run 'TaskDateParserTest'**. Ожидаем два пройденных теста.
7. На телефоне включите **Режим разработчика → Отладка по USB**, подключите кабелем и разрешите отладку на телефоне. Выберите свой телефон наверху Android Studio и нажмите зелёный **Run ▶**.
8. В приложении попробуйте вводить буква за буквой: `Домашка завтра в 18:00`. Проверьте, что программа не закрывается, затем добавьте задачу.
9. Для диагностики откройте **View → Tool Windows → Logcat**, выберите телефон и установите фильтр `package:ru.svoizadachi.app is:crash`. При новом вылете скопируйте блок **FATAL EXCEPTION** и строки **Caused by**.

**Внимание:** APK из GitHub Actions и APK из Android Studio могут иметь разные debug-подписи. Если Android Studio выдаст `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, удалите старое приложение «Свои задачи» с телефона и повторите Run. Это удалит задачи старой тестовой версии.

**Что исправлено в v0.1.1:** удалены неподдерживаемые Android модификаторы регулярных выражений; Unicode-границы слов теперь заданы явно и одинаково работают на Android и Java. Написаны дополнительные проверки каждого префикса при посимвольном вводе. Логику парсера проверили локально на JDK (310 проверок). Полный APK этой ревизии ещё не собирался и не запускался на реальном Android устройстве — это нужно сделать в Android Studio.

## Получить APK через GitHub Actions (бесплатно)

1. Создайте новый пустой репозиторий на [github.com/new](https://github.com/new), например `SvoiZadachi`.
2. Загрузите **содержимое** этой папки (а не сам ZIP), сохранив все подпапки, **включая скрытую `.github/workflows`**. Это можно сделать через `git push` с компьютера или через GitHub Web/ Codespaces.
3. Откройте вкладку **Actions → Собрать APK → Run workflow** (или дождитесь сборки после первого push).
4. После успешной сборки откройте её и скачайте артефакт **SvoiZadachi-debug-apk**.
5. Внутри архива будет **app-debug.apk**, который можно установить на свой Android-телефон.

Для первого теста используется стандартная **debug-подпись**, не используйте её для официальной публикации и не храните в тестовой версии важные данные.

## Настройка уведомлений (OnePlus / Android 15–16)

После установки разрешите:
- **Уведомления** для приложения «Свои задачи».
- **Будильники и напоминания / точные напоминания**, если система предложит.
- При задержках уведомлений проверьте ограничения фоновой работы и энергосбережения для приложения в настройках телефона. 100% гарантию доставки уведомлений Android не даёт.

## Проверить парсер без Android SDK

Требуется JDK 17+. Из корня проекта:

```bash
mkdir -p parser-tests
javac -encoding UTF-8 -d parser-tests app/src/main/java/ru/svoizadachi/app/TaskDateParser.java tests/ParserTest.java
java -cp parser-tests ParserTest
```

## Сборка локально с Gradle и Android SDK

Нужны JDK 17, Gradle 8.9 и установленный Android SDK 35:

```bash
gradle :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Технологии

Java 17, Android API 26+, Gradle, системные Android UI/AlarmManager/NotificationManager, `SharedPreferences` + JSON. Никаких внешних библиотек и серверов. Лицензия MIT.
