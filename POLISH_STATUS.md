# Sadachi: проверяемый статус полировки (локальная рабочая версия)

## Сделано

- Причина обрыва записи на 60-й секунде: абсолютный дедлайн в `VoiceInput`. Теперь запись по умолчанию длится до 10 минут; в настройках доступны 2/5/10 минут, ручная остановка остаётся основной. 16-kHz mono PCM передаётся Vosk порциями, а не сохраняется в виде полного аудиофайла. Последний прочитанный буфер обрабатывается до проверки тишины, `getFinalResult()` вызывается после остановки.
- Добавлены счётчик времени, обновлённые палитра Sadachi, векторные иконки заголовка, согласованная терминология списков, пустое состояние без бессмысленного кружка, плавное изменение высоты редактора, Undo удаления и кнопка микрофона в достаточно широком виджете. Сохраняются существующий формат данных, локальный Vosk, задачи, напоминания и iOS-подобная тема.
- Виджет открывает голосовой ввод через отдельный intent и запрашивает разрешение в приложении. Остановка записи при уходе приложения в фон остаётся преднамеренной: фонового microphone foreground service пока нет.

## Не заявлять готовым

- Улучшение точности русской речи, сравнение Vosk с whisper.cpp, WER и целевые 95% **не проверены**: нет эталонных аудиозаписей с расшифровками для одного и того же набора. Существующие 100 комбинаций — тесты текстового парсера, не аудио. Более крупный движок нельзя выбирать только по обещанию качества: нужны измерения WER, скорости, RAM и батареи на реальных целевых телефонах в тишине и шуме.
- Облачный STT/LLM **не реализован**. Нет согласованного сервера для секретов, политики обработки аудио/согласия и защищённого канала. Встраивать открытый API-ключ в APK нельзя. Приложение остаётся офлайн, неоднозначные фразы требуют ручной проверки перед пакетным сохранением.
- Срок задачи и время напоминания пока используют одни поля модели; фразы «задача через час» и «напомни через час» семантически не разделены. Это требует миграции схемы хранения и проверки обратной совместимости, а не изменения одной подписи в UI.
- Полная система экранных переходов, настраиваемый waveform-виджет разных размеров, отдельный виджет быстрого добавления, подтверждённые 60 FPS и тестирование длительной записи **не завершены**. Не было визуального подтверждения на Android-устройстве. Эмулятор API 37 x86_64 в среде не запустился без hardware acceleration.
- Для реальной проверки нужны Android-устройство, набор из 100 согласованных русских аудиозаписей с эталонными транскрипциями и отдельными ожидаемыми полями задач, а также согласие на использование устройства и на облачную обработку, если она потребуется.

## Воспроизведение проверки кода

Скопировать исходники в ASCII-путь на Windows (Android Gradle Plugin отклоняет кириллицу в пути), установить `ANDROID_HOME`, выполнить `:app:testDebugUnitTest :app:assembleDebug`. Debug APK из локального дерева без внедрённого CI-архива `voice-ru-0.22.zip` не подходит для проверки распознавания; в CI архив добавляется отдельно. Не устанавливать локальный APK поверх пользовательской версии: ключ debug-подписи может отличаться.
